# 16:9 人物立绘提示词专门技能规范（半身大头照主视图 + 三张侧式图）

本规范专用于指导 AI 编剧与资产设计师为剧本角色生成高质量的 16:9 横屏多视图人物立绘设定图提示词（art_prompt）。

---

## 一、硬性排版与画幅规范

1. **画幅比例硬性为 16:9**：
   - 默认生成人物立绘提示词比例应为 16:9；
   - 出图提示词内容中必须明确写明：`16:9比例画面`，且末尾附带 `--ar 16:9`。
2. **四视图排版结构**：
   - **画面左侧主视图**：人物上半身正面特写（半身大头照作为主视图），重点呈现面部五官轮廓、眼睛神韵、精致妆容、发型发丝、头饰发冠、耳坠项链与服饰领口细节；
   - **画面右侧三张侧式图**：并列展示人物全身正面、全身侧面、全身背面三个视图（三张侧式图），人物完整站立，从头到脚全身入镜，比例协调，高端海报质感；
   - **同一人物一致性**：左侧半身大头照主视图与右侧三张侧式图必须严格为同一人物，发型、头饰、服饰款式、色彩纹样与材质完全一致。

---

## 二、五大模块结构化公式

出图提示词必须采用结构化模块编写：

```
【画面类型】+【排版结构】+【人物本体】+【造型细节】+【材质描述】+【光影背景】+【风格限制】
```

1. **画面类型**：超写实真人摄影写真 / 角色设定图 / 专业人像摄影 / 8K超清 / 照片级真实质感 / 85mm f1.4镜头 / 浅景深 / 人物四视图排版设定图。
2. **排版结构**：16:9比例画面；左侧为人物上半身正面特写（半身大头照主视图），展现面部五官细节；右侧并列展示人物全身正面、全身侧面、全身背面三张侧式图，三视图人物服装发型完全一致，完整站立入镜。
3. **人物本体**：年龄感、肤色肤质、五官脸型、眼神神态、唇妆与伪素颜感、气质类型。
4. **造型与材质**：发型蓬松自然、头饰材质与镶嵌、服饰主色调与剪裁层叠、刺绣暗纹、配饰，特别强调背面长发与披帛/后背纹样可见。
5. **光影背景与限制**：米灰色柔光摄影棚背景（柔和高级）；电影级自然柔光，侧逆光勾勒发丝轮廓，柔和面光打造清透素颜感；限制词：照片级真实质感，无插画感，无二次元感，无3D建模感，无手绘卡通感，无塑料假皮感；结尾追加 `--ar 16:9`。

---

## 三、调优经验（防偏与一致性）

- **如果不像同一个人**：提示词强制追加 `左侧特写与右侧三视图必须为同一人物，same person, facial consistency`。
- **如果背面细节被忽略**：专门写明 `背面长发层次清晰，后背刺绣暗纹与腰饰可见`。
- **如果偏向插画卡通**：强化 `8K真实人像摄影写真，真实皮肤肌理，影棚打光，无插画感无CG感`。
