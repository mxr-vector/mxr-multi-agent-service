# 人物立绘与多视图角色设定图设计技能 (Character Portrait & Model Sheet Designer)

专用于为 GPT-Image-2、Midjourney、Seedream、Nano Banana 等主流图像生成模型编写高质量、高稳定性的人物立绘与多视图角色设定图提示词。

---

## 一、核心定位与排版规范（必须严格遵循 16:9）

在影视短剧、动画制作和游戏美术中，单张角色特写容易生成，但制作管线需要的是**角色设定型输出（Character Model Sheet）**，用于固定角色长相、发型、服装和多角度造型。

### 1.1 画幅比例硬性规定
- **默认生成画幅比例必须为 16:9**（宽屏横图设定海报，适配影视视频资产库与屏幕展示）。
- 出图提示词正文中必须明确写明：`16:9比例画面`，且结尾必须附带参数标记：`--ar 16:9`。

### 1.2 左右排版结构（半身大头照主视图 + 三张侧式图）
画面横向分为左右两大部分：
1. **画面左侧（主视图）**：
   - **人物上半身/正面特写（半身大头照作为主视图）**。
   - 重点清晰展示：面部五官轮廓、眼睛神态、精致妆容、发型发丝、头饰发冠、耳坠颈饰与服饰领口细节。
2. **画面右侧（三张侧式图并列）**：
   - **并列展示人物全身正面、全身侧面、全身背面三个视图（三张侧式图）**。
   - 人物从头到脚全身完整入镜、完整站立、比例协调、无肢体截断。
3. **同一人物高度一致性（核心铁律）**：
   - 左侧半身大头照主视图与右侧三张侧式图必须严格为**同一人物**。
   - 面部五官特征、发型、发色、头饰、服饰款式、色彩纹样、材质完全一致。

## 二、万能结构化 5 大模块公式

生成高质量角色设定图，核心不是简单堆砌形容词，而是将提示词写成结构化指令：

```
【画面类型】 + 【排版结构】 + 【人物本体】 + 【造型细节】 + 【材质描述】 + 【光影背景】 + 【风格限制】
```

### 模块 1：定义画面类型（定调）
先给模型定调，杜绝概念草图或低劣插画感：
- 超写实真人摄影写真 / 角色设定图 / 专业人像摄影 / 8K超清 / 极致细节 / 照片级真实质感 / 85mm f1.4大光圈镜头 / 浅景深 / 焦点精准 / 人物四视图排版设定图。

### 模块 2：明确排版结构（最关键一步）
明确向模型指定画面左右分布与视图关系：
- 16:9比例画面；画面左侧为人物上半身正面特写（半身大头照主视图），展示面部神态、妆容发饰与服饰细节；画面右侧并列展示该人物全身正面、全身侧面、全身背面三张侧式图，三视图人物服装发型完全一致，完整站立，全身入镜，比例协调，高端角色设定海报质感。

### 模块 3：写清人物本体（辨识度特征）
具体刻画人物核心特征，避免千人一面：
- 年龄感（如：年轻亚洲女性/俊朗青年剑客）
- 人种与肤色（如：清透冷白肌肤、健康小麦色皮肤、细腻水润通透）
- 脸型与五官（如：小巧瓜子脸、小鹿眼、深邃眼眸、剑眉星目）
- 妆容与表情（如：伪素颜清透妆、裸色水润唇妆、眼神纯净冷冽、表情沉稳自然）
- 气质类型（如：空灵仙气、冷峻孤傲、清纯治愈）

### 模块 4：把造型与材质拆开写（分项细化）
造型细节拆分为发型、头饰、服装、配饰四个维度：
- **发型**：长短、发色、盘发/披发、蓬松自然发丝、碎发修饰脸颊。
- **头饰**：材质（白银、原木、玉石、翡翠、金属）、雕花工艺、镶嵌宝石、流苏垂挂与额间眉心坠。
- **服装**：款式类型（襦裙、铠甲、风衣、衬衫）、主色调（明晰主辅色，如薄荷绿搭配米白与浅烟粉）、剪裁层次、刺绣暗纹（如铃兰纹、云纹、兽纹）。
- **配饰**：耳坠、项链、腰封腰佩、护腕、鞋履。
- **背面细节强调**：背面长发层次分明、后背刺绣图案与披帛自然垂落可见，确保背视图不偷工减料。

### 模块 5：光影背景与风格限制（质感兜底）
- **背景与光影**：米灰色柔光摄影棚背景（或纯净柔光摄影棚背景，干净高级，衬托主体）；电影级自然柔光，侧逆光细腻勾勒发丝轮廓，柔和面光打造通透肤质，凸显衣物与配饰层次。
- **风格限制与防偏**：照片级真实质感，无插画感，无二次元感，无3D建模感，无卡通感，无塑料假皮感。
- **结尾画幅标记**：`--ar 16:9`。

## 四、常见生成问题与优化调优策略

1. **如果三视图与主视图不像同一个人**：
   - 补强强制一致性描述词：`左侧特写与右侧三视图必须为同一人物（same person, same face identity）`、`面部五官轮廓在四个视图中保持绝对统一`、`发型头饰服饰无任何变动`。
2. **如果背面细节丢失或简化**：
   - 在造型模块专门给背面加戏：`背面长发层次清晰`、`背面可见服饰刺绣纹样与腰封结构`、`披帛在背后自然垂落无遮挡`。
3. **如果画面出现插画感/卡通CG感**：
   - 加重写真摄影限定词：`8K照片级真实摄影`、`真实皮肤毛孔与肌理感`、`专业单反相机实拍质感`、`真实影棚灯光布光`；
   - 并在末尾明确声明限制：`无插画感，无CG感，无二次元漫画感，无3D建模感，无假皮塑料质感`。
4. **如果排版错乱、视图重叠**：
   - 检查排版结构语句是否明确写出：`画面左侧为上半身特写主视图，画面右侧并列展示全身正面、全身侧面、全身背面三个独立全身视图，横向一字排开，互不遮挡，完整站立入镜，16:9比例画面，--ar 16:9`。
