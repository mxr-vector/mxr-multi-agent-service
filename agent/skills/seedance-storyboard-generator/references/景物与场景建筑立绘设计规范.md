# 16:9 景物与场景建筑立绘提示词专门技能规范（概念主视图 + 空间细节特写）

本规范专用于指导 AI 编剧与资产设计师为剧本中的 **景物、场景建筑、空间地标与重要道具** 生成高质量的 16:9 横屏多视角概念设定图与资产提示词（art_prompt），适用于「纯景意境 / 场景变换」模式及剧情短剧中的空间与道具资产生成。

---

## 一、硬性排版与画幅规范

1. **画幅比例硬性为 16:9**：
   - 景物与建筑立绘提示词默认比例必须为 16:9；
   - 出图提示词内容中必须明确写明：`16:9比例画面`，且末尾附带 `--ar 16:9`。
2. **多视角与细节概念排版结构**：
   - **画面左侧主视图**：建筑 / 景物 / 道具的主体全貌概念设计主视图，展现宏大空间形态、建筑规制、比例体量与环境融合感；
   - **画面右侧细节视图**：并列展示局部结构特写（如飞檐斗拱、雕花门窗、青石台阶、水波倒影、材质纹理质感）或不同视角透视（正面全貌、侧向透视、特写构件）；
   - **同一景物一致性**：左侧概念主视图与右侧细节特写必须严格对应同一空间建筑/景物主体，材质、年代感、色彩与空间风格完全一致。
3. **严格杜绝人物与人形化**：
   - 景物与建筑立绘中**严禁出现任何人物、人影、面孔、肢体、站姿与服装**；
   - 严禁套用人物四视图（严禁出现半身大头照、面部五官轮廓、全身正面侧面站姿等人物概念）。

---

## 二、五大模块结构化公式

出图提示词必须采用结构化模块编写：

```
【画面类型】+【排版结构】+【景物/建筑/道具主体】+【材质与细节】+【光影环境与氛围】+【风格与质感限制】
```

1. **画面类型**：超写实概念设计图 / 影视级场景概念美术设定图 / 建筑摄影写真 / 8K超清 / 照片级真实质感 / 空间概念多视角排版设定图。
2. **排版结构**：16:9比例画面；左侧为景物/建筑主体全貌概念主视图，展现整体空间轮廓与环境气势；右侧并列展示局部结构特写与材质纹理细节，构图高端大气，具有影视概念美术设计质感。
3. **景物/建筑主体**：名称、时代背景、建筑类型/自然景观特征、空间体量与构图层次（如深山古寺、断桥烟雨、飞檐斗拱、乌篷孤舟、古琴香炉等）。
4. **材质与细节**：详细描述材质纹理与岁月痕迹（如青砖灰瓦、古木榫卯雕花、青苔石阶、残雪水光、木纹肌理、金箔剥落、琉璃瓦反射等）。
5. **光影环境与限制**：真实自然采光、丁达尔光线、清晨薄雾、暮色暖阳或烟雨朦胧；
   - **硬性限制词**：纯净空间，无人物出镜，无人影，无面孔，无肢体，照片级真实质感，无插画感，无二次元感，无3D建模塑料感；
   - 结尾追加 `--ar 16:9`。

## 三、标准提示词范例

### 范例 1：建筑类（深山古刹 / 石拱桥）
```
超写实影视级场景概念美术设定图，8K超清，极致细节，照片级真实质感，16:9比例画面。画面左侧为江南古朴石拱桥全貌概念主视图，石桥横跨于如镜水面之上，展现宋代建筑规制与舒展弧度；画面右侧并列展示两张局部特写图（青石台阶上的湿润青苔与岁月磨损痕迹，以及桥栏望柱上的古朴石雕纹理）。青灰石材肌理分明，烟雨江南氛围，清晨薄雾弥漫，柔和漫射光影，空灵悠远意境。无人物出镜，无人影，无插画卡通感。 --ar 16:9
```

## 四、调优与防偏经验

- **若画面容易生成人物**：提示词强制强化 `纯景物设计，纯建筑设计，画面中严禁出现任何人物或人影，empty scene, no people, no human figure`。
- **若排版混乱**：显式指定 `16:9横屏画面，左边概念全景主视图，右边局部材质特写`。
- **若风格偏CG假皮**：强化 `照片级真实材质肌理，自然物理采光，环境漫射光，无塑料感，无手绘二次元感`。
