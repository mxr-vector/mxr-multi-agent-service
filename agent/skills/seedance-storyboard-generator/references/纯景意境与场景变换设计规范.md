# 纯景意境与场景变换设计规范

专用于 **纯景意境 / 风光漫游 / 场景变换** 类 AI 视频分镜设计（无人物、无剧情、纯以场景视觉流转与美学氛围驱动）。

---

## 一、核心定位与适用场景

当用户需求为：
1. **纯自然风光与季节更替**（如：烟雨江南、西湖十景、四季流转、雪山林海、星空银河）
2. **建筑与空间氛围漫游**（如：深山古寺、赛博朋克夜雨街头、未来太空站、废墟美学）
3. **唯美意境与情绪定格**（如：禅意茶道空镜、晨曦微光、暮色晚霞、光影斑驳）
4. **展演与空镜转场**（为主片垫场或作为独立治愈系风光视觉大片）

**核心原则：**
- **严禁强行虚构人物**：不要捏造"游客A"、"游侠"、"主角"等无意义角色。
- **无须戏剧矛盾冲突**：不需要冲突前置、打脸反转、对白内心独白与钩子。
- **以空间推进与光影流动为叙事主线**：用摄影机运动（推拉摇移、俯瞰穿梭）、景别律动（大全景建立 → 中景环境 → 微距特写 → 仰拍震撼）与时空变化（晨昏、四季、晴雨）推动视觉情绪。
- **严禁生成字幕**：不出现【字幕：xxx】，画面纯净。
- **角色卡与资产**：结构化数据块中 `characters` 为 `[]`（空数组），专注于生成高质量的场景与关键帧出图提示词。

---

## 二、六段式文本结构规范

在纯景意境模式下，剧本/分镜正文按以下结构组织：

```markdown
# [标题] - 意境分镜脚本

一、核心意境与美学风格
[美学风格定义：如中国传统水墨设色/电影级写实纪录片/暗调赛博朋克；主色调、光影质感、自然元素与虚实留白]

二、场景时空流转梗概
[整体空间推进路线与时间跨度：例如从晨曦薄雾到正午明澈，再到暮色残阳与夜幕星河；或从高空俯瞰到深入庭院微观]

三、一句话意境描述
[诗意且具有强烈视觉画面的总结：如「孤舟蓑笠入烟雨，一蓑烟雨任平生，江南水乡四时光影的诗意流转」]

四、视觉亮点与空间设计
[场景关键视点与美学元素拆解：如古朴飞檐、水波倒影、雨丝涟漪、青苔石阶等]

五、场景变换大纲
[分集或分幕的场景推进逻辑，单集控制在 15s 或 30s 节奏内]

六、分镜正文
```

---

## 三、分镜正文格式（以集为单位，每集最多 15s 或 30s）

每一集包含 3-6 个场景变换镜头，镜头累计秒数严格等于单集预估时长：

```markdown
第1集：晨曦与烟雨（预估生成时长：15秒）
1-1 外景 [清晨/薄雾] [西湖断桥]
预估时长：15秒
出场人物：无（纯景空镜）

△ 【关键帧 1-1】（预估 3秒）[远景大俯拍·缓慢推近] [晨曦微光·冷蓝渐变金橙] 晨雾笼罩的平静湖面，断桥残雪与枯柳在薄雾中若隐若现，天际线泛起第一缕极淡的晨曦暖金。
△ 【关键帧 1-2】（预估 3秒）[中景平移摇镜] [柔和漫射光] 镜头贴近水面缓慢横摇，细密雨丝在水面荡开层层轻柔涟漪，远处黑瓦白墙的江南民居倒映水中，虚实相生。
△ 【关键帧 1-3】（预估 3秒）[微距特写·缓慢升降] [清透逆光] 乌篷船青石跳板旁，一枝探出水面的荷叶尖端，雨滴凝聚滑落，水珠折射晶莹光泽。
△ 【关键帧 1-4】（预估 3秒）[全景仰拍·镜头微仰] [天光渐明] 镜头从水面升起，古朴石拱桥横跨画面中央，晨风拂动垂柳枝条，雾气渐渐随风散开。
△ 【关键帧 1-5】（预估 3秒）[大全景拉远] [开阔晨光] 镜头平稳拉升至半空，整个西湖水面如水墨画卷般舒展，孤舟泊在岸边，意境空灵悠远。
```

## 四、Seedance 2.0 纯景提示词模板（时间轴）

```
[视觉风格]，15秒，16:9横屏，[核心光影氛围]

0-3秒：[大全景建立] - [极简空镜] - [慢速推镜头]，湖面雾气流淌，远山如黛，晨曦破晓
3-6秒：[中景视角] - [平移摇镜]，雨丝落入水面，泛起涟漪，岸边垂柳轻拂
6-9秒：[特写细节] - [微距慢动作]，雨滴滑落青瓦飞檐，水花飞溅特写
9-12秒：[空间穿透] - [低角度穿行]，穿过曲径通幽的石桥拱券，水光潋滟
12-15秒：[升空全景] - [平稳升降拉远]，全景水墨画卷落版，空灵沉静

【声音】只生成音效，不要生成音乐，不要生成字幕。细雨淅沥声、微风拂柳沙沙声、水滴石阶清脆声。
```
