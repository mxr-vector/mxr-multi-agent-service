# 实体扩展通道迭代报告（2026-08-23，方向①取证锚定 + 方向②独立重排/保留席位）

## 基线

生产语义臂上轮结果（entity_bridge_index_final_report.md）：多跳 bridge@10=0.119、
hop@10=0.454、recall@10=0.166，经由扩展命中 top-10 跳组 0/781。

## 本轮改动

1. **实体锚定取证**：`link_and_expand` 返回文档→实体归因（`doc_entity_provenance`），
   `fetch_expansion_chunks` 取"含桥接实体的首个叶块"替代文档 top-1 块（回退首块）。
2. **扩展通道独立重排 + 保留席位**：主路按原问题统一终排；扩展候选用
   "原问题 + 桥接实体"专用查询独立重排，按 `EXPANSION_FINAL_QUOTA=2` 席位注入终排
   尾部（`merge_final_with_expansion`，跨查询不比分、`source_hops=[2]` 溯源）；
   席位未填满由主路尾部回填，恒定返回 top_n。
3. **关键 bug 修复（影响历史结论）**：扩展通道输出的 document_id 为带连字符 UUID，
   主路候选与评测 gold 均为无连字符 hex，导致扩展文档永远无法匹配 gold——
   此前所有"扩展 0 贡献"的结论均被此评测假象污染。已归一化为 hex。

## 诊断结论

- gold 在扩展候选中的覆盖：395/542 可链接题（72.9%），其中 186 题仅在扩展文档中。
- 仍被终排淘汰 659 跳组：扩展候选 gold 的独立重排名次多在 quota×3=6 名之外，
  席位有限，属于通道容量约束而非信号失效。
- 中途负结果存档：仅锚定取证不注入席位（`*_anchoronly_*`）无增益；带席位但 id
  失配（`*_quota_dashedid_*`）指标回退且 via_expansion=0，均为评测假象/机制缺陷的
  对照证据。

## 后续方向

- 席位/余量超参扫描（quota 2→3、余量 ×3→×5），观察 659 个"进终排未被选中"跳组
  的可回收上限；
- 扩展候选按实体重合度预排序后再重排，提升 gold 进入前 2 名的比例；
- 结构化语料复验（当前同质语料仍是下限测试）。
